2. W3 NAMING SCHEMES - ORIGEN DE LA URL

=== W3 NAMING SCHEMES - ORIGEN DE LA URL - 1990 ===
Autor: Tim Berners-Lee - timbl@info.cern.ch

Formato inventado:
scheme://host.domain:port/path/path#anchor
?words+separated+by+plus = search index

Ejemplos 1990:
file://cernvax.cern.ch/usr/lib/WWW/default.html#123
#greg = anchor en mismo doc

Esquemas definidos:
- file
- news (NNTP)
- http (search and retrieve)
- telnet
- gopher
- wais (Z39.50)
- x500 (to be defined)

Problema resuelto: nombre lógico vs dirección física.
" A hypertext link to a document ought to be specified using 
the most logical name as opposed to a physical address.
This is (almost) the only way of getting over the problem 
of documents being physically moved."

Comandos Line Mode Browser:
[1] [2] = referencias
f = find
b = back, n = next, q = quit, u = up, d = down
p = print, > file = save, | command = pipe
! command = shell, CD directory
Help = lista comandos + UDI (hoy URI/URL)

Bug reports: www-bug@info.cern.ch

3. W3 ADDRESS SYNTAX BNF - GRAMMAR

=== W3 ADDRESS SYNTAX: BNF - TIM BERNERS-LEE 1990 ===
Origen: info.cern.ch - The original URL grammar

BNF DEFINICION ORIGINAL PEGADA EN ARKHE ZERO:

anchoraddress ::= docaddress [ # anchor ]
docaddress ::= httpaddress | fileaddress | newsaddress | 
               telnetaddress | prosperoaddress | 
               gopheraddress | waisaddress

httpaddress ::= http://hostport[/path][?search]
fileaddress ::= file://host/path
newsaddress ::= news:groupart
waisaddress ::= wais://hostport/database[?search]
telnetaddress ::= telnet://[user@]hostport
gopheraddress ::= gopher://hostport[/gtype[/selector]][?search]

hostport ::= host[:port]
host ::= hostname | hostnumber (digits.digits.digits.digits)
path ::= void | xalphas[/path]
search ::= xalphas[+search]

xalpha ::= alpha | $ | _ | @ | ! | % | ^ | & | * | ( | ) | . | digit
alpha ::= a-z | A-Z
digit ::= 0-9

=== VALOR FORENSE ===
Este BNF es la primera especificación formal de URL en historia.
De aquí nace:
- http:// que usas hoy
- file:// que usas en Termux /mnt/data/
- #anchor que usas en HTML
- ?search con + que hoy es ?q= + Google

Tim BL lo escribió con | para alternativas y [brackets] para opcional.
"Spaces are representational only: no spaces are actually allowed 
within a W3 address."
