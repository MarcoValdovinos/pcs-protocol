# 🚀 Tutorial 01 · Primeros Pasos

## 🜂 Requisitos

- Node.js >= 20
- Git
- Un editor de texto

## 🜃 Pasos

### 1 · Clonar

```bash
git clone https://github.com/marcojas17/kronos-protocol.git
cd kronos-protocol
```

### 2 · Instalar

```bash
make install
```

### 3 · Verificar Índice Cero

```bash
kronos verify --chain genesis
```

### 4 · Servidor MCP

```bash
cd marco.mcp
npm install
npm run build
node dist/index.js
```

### 5 · Ver la web

Abrir `index.html` en navegador.
